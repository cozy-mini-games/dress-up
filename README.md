# 換裝小屋 👗

送給朋友的 Q 版換裝小遊戲（手機網頁，GitHub Pages）。

網址：https://b0966836079-afk.github.io/dress-up/

## 給以後的 Claude：這個專案怎麼做的
- 跟「喵喵小窩」（repo `b0966836079-afk/meow`）是**完全分開**的專案，不要混在一起。
- 前端：純 HTML/CSS/JS，沒有打包工具，放在 GitHub Pages（main 分支根目錄）。
- 圖片素材在 `img/`，**所有圖層都是同一個畫布 339×610**，疊上去就對齊：
  - `img/base.png`：素體（含臉，無頭髮），透明背景。
  - `img/hair/N_back.png`（在身體後面）、`N_front.png`（瀏海，蓋在臉上）、`N_icon.png`（選單小圖）。
  - `img/face/blink.png`、`happy.png`：閉眼／笑眼表情，蓋在眼睛上（眨眼、被摸頭時用）。
  - 疊放順序：hairBack → base →（之後的衣服）→ face → hairFront。
- 互動（index.html 下半部）：自然眨眼、點頭部＝摸頭（笑眼＋愛心）、點身體＝跳一下、換髮型＝轉圈、太久沒點會自己說話、連點 6 下會害羞。台詞在 `LINES`。
- `index.html` 裡的 `CATS` 是素材清單，加新髮型/衣服/背景只要加一行。選擇存在 localStorage `dressup`。「存成照片」用 canvas 合成下載。
- 髮型對齊做法：把頭髮依「臉洞」中心和下緣對到素體的頭（頭中心 x=168、下巴 y=248，畫布座標）。back 層＝整頂頭髮放身體後面；front 層＝下巴以上、扣掉臉部橢圓（cx168 cy222 rx66 ry56，羽化 3px）的頭髮，頭頂沒蓋到的空隙用附近頭髮的紋理補。眼睛位置：左 (130,192)、右 (209,192)。
- 素材來源：使用者用 ChatGPT / Gemini 之類的 AI 生成（同一張素體、只換衣服或頭髮），再傳給 Claude 去背、對齊。
  - 去背做法：從邊緣 flood fill，遇到深色輪廓線停下（亮度門檻約 190），再只保留最大的連通區塊，邊緣輕微模糊。
  - 要使用者「下載原圖」再傳，不要截圖（截圖太小會糊）；提示詞要寫「純白背景、完全相同的人物/姿勢/大小/位置」。

## 給以後的 Claude：使用者與合作方式
- 使用者說繁體中文（台灣），用 Redmi（Android）手機。
- 使用者不會寫程式：**直接推到 GitHub**，不要叫她上傳檔案。每一步都要講清楚，並附上連結。
