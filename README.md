## 給以後的 Claude：這個專案怎麼做的
- 跟「喵喵小窩」（repo `b0966836079-afk/meow`）是**完全分開**的專案，不要混在一起。
- 前端：純 HTML/CSS/JS，沒有打包工具，放在 GitHub Pages（main 分支根目錄）。
- 圖片素材在 `img/`，**所有圖層都是同一個畫布 339×610**，疊上去就對齊：
  - `img/base.png`：素體（含臉，無頭髮），透明背景。
  - `img/hair/N_back.png`（在身體後面）、`N_front.png`（瀏海，蓋在臉上）、`N_icon.png`（選單小圖）。
  - `img/face/blink.png`、`happy.png`：閉眼／笑眼表情，蓋在眼睛上（眨眼、被摸頭時用）。
  - 疊放順序：hairBack → base →（之後的衣服）→ face → hairFront。
- 互動（index.html 下半部）：自然眨眼、點頭部＝摸頭（笑眼＋愛心）、點身體＝跳一下、換髮型＝轉圈、太久沒點會自己說話、連點 6 下會害羞。台詞在 `LINES`。
- `index.html` 裡的 `CATS` 是素材清單，加新髮型/衣服/背景只要加一行。選擇存在 localStorage `dressup`。「存成照片」用 canvas 合成下載。
- 髮型對齊做法：把頭髮依「臉洞」中心和下緣對到素體的頭（頭中心 x=168、下巴 y=248，畫布座標）。back 層＝整頂頭髮放身體後面；front 層＝下巴以上的頭髮，臉部窗口＝臉部橢圓下半（cx168 cy222 rx64 ry56）＋上方每一欄在瀏海自己的髮尾切（限制在 y150～178 之間），所以瀏海保留原本的髮尾形狀、垂到睫毛上；瀏海下加淡陰影，頭頂沒蓋到的空隙用附近頭髮的紋理補。眼睛位置：左 (130,192)、右 (209,192)。
- 素材來源：使用者用 ChatGPT / Gemini 之類的 AI 生成（同一張素體、只換衣服或頭髮），再傳給 Claude 去背、對齊。
  - 去背做法：從邊緣 flood fill，遇到深色輪廓線停下（亮度門檻約 190），再只保留最大的連通區塊，邊緣輕微模糊。
  - 要使用者「下載原圖」再傳，不要截圖（截圖太小會糊）；提示詞要寫「純白背景、完全相同的人物/姿勢/大小/位置」。

## Claude 自己畫的頭髮（向量）
- 第 4 款（深棕長髮＋髮髻＋桃花簪）是 Claude 用 SVG 照素體的頭直接畫的，原始檔在 `tools/hair4_front.svg`、`tools/hair4_back.svg`（畫布 339×610 座標）。
- 做法：front＝頭頂＋瀏海＋兩側髮束（蓋住耳朵）＋髮髻＋飾品；back＝身體後面的長髮。用 Playwright 以 3 倍解析度轉 PNG 再縮小，front 再加瀏海陰影（front alpha 往下 4px、模糊 2px、只在皮膚上、透明度 0.45）。
- 頭的位置：頭頂 y≈75、頭中心 x=168、太陽穴寬 x 90～246、下巴 y=248、眼睛上緣 y≈172（瀏海髮尾停在 y≈170～186）。

## App（PWA）與自動更新
- `manifest.webmanifest` + `icons/`：可以「加到主畫面」像 App 一樣打開。右上角「下載 App」按鈕：Android Chrome 會直接跳安裝；iPhone 顯示 Safari 加入主畫面的步驟。
- `sw.js`：有網路時一律抓最新版（network-first, `cache:'no-cache'`），沒網路才用快取。App 每分鐘和每次切回前景會檢查新版，有新版自動重新整理並顯示「已更新到最新版」。
- **每次改檔：`sw.js` 的 `VERSION` +1**，再 commit、`git push origin HEAD:main`。

## 更新流程
改好程式 → 推到 `main` → GitHub Pages 約 1～2 分鐘後上線 → 手機重新整理。
